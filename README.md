# HawkesTechnologies.com

Repo for my LLC — built with [React](https://react.dev) + [Vite](https://vite.dev).

## Development

```bash
npm install       # install dependencies
npm run dev       # start dev server (http://localhost:5173)
npm run build     # production build → dist/
npm run preview   # preview production build locally
npm run lint      # run ESLint
```

## Stack

- **React 19** — UI library
- **Vite 8** — build tool & dev server (HMR, fast cold starts)
- **[@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react)** — React fast-refresh via [Oxc](https://oxc.rs) transforms
- **ESLint** — linting
